# 数据卡：telecom-synthetic-v1

- 任务数：60。
- 故障类别：12 类，每类 5 条。
- 数据类型：项目自建合成告警、合成指标、合成日志与合成运维手册。
- 生成器：`telecom_incident_agent.dataset`。
- 冻结文件：`data/evaluation/telecom_eval_v1.jsonl`。
- 完整性：UTF-8 文本统一 LF 后计算 SHA-256，值记录在 manifest。
- 生产数据：无。
- 个人信息：无。
- 运营商数据：无。
- 再分发边界：仅分发项目自建合成内容。

每条任务包含 `case_id`、数据版本、拓扑摘要、告警、日志、指标、可用工具、允许手册、预期根因、必需证据、禁止结论、风险等级、人工确认要求、允许动作和评测标签。

该数据集用于契约回归与安全门禁，不用于声称真实网络泛化能力。任务由同一代码库生成，100% 指标只能视为工程自洽性证据。
